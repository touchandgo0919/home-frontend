使用帮助

开始使用

在导航首页输入已有 Token 登录；没有 Token 时，在浏览器扩展中点击“注册并生成”，填写导航名称。注册完成后另存 Token，然后开始收藏。

收藏网页与链接

点击扩展图标，一键保存当前网页；标题和网址采用网页原文，分组沿用上次选择，首次使用时采用第一个分组。也可以右键网页或链接，选择“收藏到我的导航”；默认快捷键是 Alt/Option + Shift + S，可在 chrome://extensions/shortcuts 调整。分组可在导航网站创建和整理。

语言

扩展沿用已保存的语言偏好，否则跟随浏览器语言；书签标题保留网页原文。网站顶部也可以切换语言。

数据导入与导出

登录首页，打开“数据与备份”。可导出 HTML（兼容浏览器书签）或 JSON。导入支持 Chrome 导出的 HTML 和本站 JSON，每次最多 1000 条、文件不超过 1 MB。可修改目标分组名称，预览后确认合并；重复及无效网址会跳过。

删除与恢复

删除书签或分组后会进入回收站，保留 30 天。可立即撤销，或在“数据与备份 → 回收站”恢复。恢复分组仅恢复与该分组一同删除的书签。

自动备份

每天北京时间 03:00 自动创建独立备份，保留 35 天。在“自动备份”查看状态、下载自己的数据，或预览合并恢复。恢复保留现有书签和 Token；同一网址不会重复导入。

Token 与登录

Token 是登录凭据，请另存到可信位置。网站顶部和扩展中都能复制 Token。登录信息默认保留 99 年，退出、清除浏览器数据、卸载扩展或服务器撤销 Token 会结束登录。没有邮箱找回功能。不要把 Token 发到公开页面或反馈中。

安装与更新

应用商店版本发布后由 Chrome 更新。在此之前，可在 chrome://extensions 开启开发者模式，加载解压后的扩展文件夹；代码更新后点击“重新加载”。1.3.0 版本要求 Chrome 127 或更新版本。

遇到问题

网络中断后先刷新确认保存结果。注册中断时点击“继续注册”，会恢复同一账号。剪贴板被拒绝时可手动复制。反馈请使用项目 GitHub Issues，并说明浏览器版本和操作步骤，不要提供 Token。

Help

Get started

Sign in on the website with your existing Token. New users can choose “Create an account” in the extension, enter a navigation name, back up the generated Token, and start saving.

Save pages and links

Open the extension and save the current page with one click. Its original title and URL are kept, and the last used collection is selected (the first collection on initial use). You can also right-click a page or link and choose “Save to My Navigation”. Alt/Option + Shift + S opens the popup; customize it at chrome://extensions/shortcuts. Create and organize collections on the website.

Language

The extension uses an existing language preference or follows your browser language. Bookmark titles keep the page’s original language. The website has its own language selector.

Import and export

Open “Data & backups” on the website. Export browser-compatible bookmark HTML or JSON. Import Chrome bookmark HTML or navigation JSON, up to 1,000 bookmarks and 1 MB per file. Rename destination collections, review the preview, then confirm. Duplicate and invalid URLs are skipped.

Trash and undo

Deleted bookmarks and collections are kept in Trash for 30 days. Undo immediately or restore them from “Data & backups → Trash”. Restoring a collection restores only bookmarks deleted together with it.

Automatic backups

Independent backups run daily at 03:00 Asia/Shanghai and are retained for 35 days. View their status, download your account’s data, or preview a merge recovery. Recovery preserves existing bookmarks and Tokens, and skips matching URLs.

Tokens and sign-in

A Token is your sign-in credential. Keep a separate trusted copy. Copy it from the website or extension. Local sign-in defaults to 99 years; signing out, clearing data, uninstalling, or server-side revocation ends it. Email recovery is not available. Never post your Token in public feedback.

Installation and updates

Once published to the Chrome Web Store, Chrome handles store updates. Until then, enable Developer mode at chrome://extensions and load the unpacked folder. Reload after updating local files. Version 1.3.0 requires Chrome 127 or newer.

Troubleshooting

After a connection failure, refresh to check whether the bookmark was saved. Continue interrupted signup to recover the same account. If clipboard access is denied, copy manually. Report issues on GitHub with browser version and steps, without your Token.
