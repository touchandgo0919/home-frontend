隐私政策

适用范围

本说明适用于“我的导航”网站及“一键收藏”浏览器扩展。更新日期：2026-10-09。

收集哪些数据

服务保存你输入的导航名称、分组，以及你主动保存或导入的网页标题和网址。Token 用于身份验证。扩展不读取浏览历史，不注入内容脚本，不持续抓取页面正文。右键收藏会处理你选择的页面或链接地址。登录后打开弹窗或修改网址时，该网址会发送至 API 查重；只有确认保存时才写入收藏及标题。

如何使用

数据用于登录、保存、查重、搜索、分组、导入导出、回收站及恢复。注册限流会使用请求 IP。我们不以这些数据开展广告定向，不出售用户数据。

Chrome Web Store 数据有限使用

扩展获取的用户数据仅用于提供和改进一键收藏及分组管理功能。除提供该功能、遵守法律、维护安全所必需的情形，或在事先取得你明确同意的业务资产转移中，我们不会向第三方转移这些数据；不会将其用于个性化、重定向或兴趣广告。人工仅在你明确请求支持、安全调查、法律要求，或处理匿名汇总的内部统计时接触数据。扩展对用户数据的使用遵守 Chrome Web Store User Data Policy 及其 Limited Use 要求。

Pro 整理功能

Pro 工具会保存你添加的书签标签、账号权益状态，以及主动检测链接时的状态和时间。链接检测只在你选择后由服务器向已保存的网址发出 HEAD 请求，目标网站可能看到该访问；检测结果缓存 24 小时。我们不下载页面正文，也不因检测结果自动删除书签。付费购买暂未开放，测试权益仅由管理员手动开通。

本地存储

扩展在 chrome.storage.local 保存 Token、语言、上次分组、注册重试信息和保存状态，不通过 Chrome Sync 同步。网站使用 localStorage 保存登录凭据、语言、主题和导航缓存。退出会清除相应登录信息；浏览器语言偏好可以保留。

服务器与服务商

API 和数据存储由 Cloudflare Workers、D1 和独立 KV 备份承载；自定义域名通过阿里云服务器提供网页及 API 转发。服务商可能处理提供服务所需的访问日志和 IP。网站加载第三方网站图标时，该图标来源可能收到请求。

保留与删除

收藏保存至你删除为止。删除后在回收站保留 30 天，自动任务在成功备份后清理过期回收站数据。独立备份保留 35 天，因此已删除数据可能暂留在历史备份内。退出或卸载扩展不会删除服务器收藏。

备份与访问

备份是私有的，包含恢复账号与收藏所需的数据及身份凭据。普通用户只能下载和恢复自己账号的收藏，导出不包含 Token。平台管理员拥有维护权限。请保管好 Token，任何持有它的人都可能操作你的账号。

你的选择与联系

可以随时导出、删除或恢复自己的收藏。若需账号级删除、隐私问题或支持，请在项目 GitHub Issues 提出不含敏感信息的请求，后续通过适当方式核实身份。不要公开 Token。

Privacy policy

Scope

This notice applies to the My Navigation website and bookmark extension. Updated: 2026-10-09.

Data handled

The service stores your navigation name, collections, and the page titles and URLs you choose to save or import. Your Token authenticates requests. The extension does not read browsing history, inject content scripts, or continuously collect page contents. Context-menu saves handle the page or link you selected. When signed in, opening the popup or editing its URL sends that URL to the API for a duplicate check. Bookmark titles and records are written only when you confirm saving.

Purpose

Data supports sign-in, saving, duplicate checks, search, collections, import/export, Trash and recovery. Signup rate limiting uses the request IP. We do not sell user data or use it for targeted advertising.

Chrome Web Store Limited Use

Data obtained by the extension is used only to provide or improve its bookmark saving and collection management features. We transfer it to others only when necessary to provide those features, comply with law, protect security, or as part of a merger, acquisition, or asset sale after obtaining your explicit prior consent. We do not use or transfer it for personalized, retargeted, or interest-based advertising. Human access is limited to user-authorized support, security investigations, legal requirements, or anonymized and aggregated internal operations. The extension's use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Pro organizer

Pro tools store the tags you add, your account entitlement, and the status and time of link checks you request. When you choose to check a saved link, our server sends a HEAD request to that URL, which the destination website may observe. Results are cached for 24 hours. We do not download page content or delete bookmarks based on check results. Purchases are not available yet; preview access is granted manually by an administrator.

Local storage

The extension stores Tokens, language, the last collection, signup retry information and save status in chrome.storage.local, without Chrome Sync. The website uses localStorage for sign-in, language, theme and navigation cache. Signing out clears the relevant login information; language preferences may remain.

Hosting providers

Cloudflare Workers, D1 and separate KV storage provide the API, database and private backups. An Alibaba Cloud server serves the custom-domain website and relays API traffic. Providers may process operational logs and IP addresses. Website favicon requests may reach the corresponding third-party icon provider.

Retention and deletion

Bookmarks are retained until you delete them. Trash retains deleted items for 30 days; a scheduled job purges expired trash after a successful backup. Independent backups remain for 35 days, so deleted data may temporarily remain in older backups. Signing out or uninstalling does not delete server bookmarks.

Backups and access

Private backups include data and credentials needed for account recovery. Regular users can download and recover only their own bookmark data; exports do not include Tokens. Platform administrators have maintenance access. Anyone who holds your Token may be able to operate your account.

Your choices and contact

You can export, delete and restore your bookmarks. For account-level deletion, privacy questions or support, open a non-sensitive request in the project’s GitHub Issues; identity verification can then be arranged appropriately. Never post your Token publicly.
